# RANA EDITOR
Android editing app project.

**Developed by Rana Haseeb**

## Build
GitHub Actions builds a debug APK on pushes to `main`. Open the Actions tab, select the latest successful run, then download the `RANA-EDITOR-debug-apk` artifact.

## Current status
This is an early Android app foundation with media picking and starter UI for Edit, Filters, Adjust and Enhance. The 500-filter catalogue, real-time filter rendering, video timeline/edit/export engine, transitions, and on-device AI enhancement are **not implemented yet**. Do not treat the current build as a finished CapCut/Remini replacement.
